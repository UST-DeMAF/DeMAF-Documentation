# Developer Guide

This guide is for developers that want to contribute to the DeMAF.

The DeMAF is organized in one [GITHUB Project](<https://github.com/UST-DeMAF>) with several (sub-) repositories.
Most of the repositories are *“Plugin”* repositories which represent functions of the tool for a specific deployment technology.

For contributing, refer to the following templates and guides:

- [Feature Branching Model](branchingModel.md)
- [Definition of Done](definitionOfDone.md)
- [Pull Request Template](pullRequestTemplate.md)
- [Guide on how to use the GitHub container registry (ghcr) and setting up the GitHub Actions correctly](ghcr/README.md).
